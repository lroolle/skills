# Meta

Skills for building, packaging, and distributing other skills.

- **[skillize](./skillize/SKILL.md)** -- Crystallize a session's workflow into a reusable skill. Surveys conversation, extracts repeatable patterns, classifies corrections by durability, drafts SKILL.md. Optional eval pipeline via skill-creator.
- **[skillbun](./skillbun/SKILL.md)** -- Bundle skills with their dependencies into distributable .skill archives. Resolves inter-skill deps, renames to avoid collisions, validates, packages.
